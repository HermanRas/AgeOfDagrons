# UI Asset Packs

The packs themselves are **not committed to this repository.** Their licence permits
personal and commercial use but **forbids redistribution of the original files**, and
committing them to a public repo would be exactly that.

Download them yourself into this folder.

## Required packs

| Pack | Source | Used for |
|---|---|---|
| **Dragon HUDs** | https://kibyra.itch.io/ui-fonts-dragon-huds-pack | Panels, buttons, bars, circular frames, icons |
| **UI Fonts** | https://kibyra.itch.io/ui-fonts-dragon-huds-pack | Project fonts |
| **Free Medieval Fantasy UI Pack** | https://kibyra.itch.io/free-medieval-fantasy-ui-pack | Additional UI chrome |

All by **Kibyra**. Free to download.

## Licence terms

Per the pack `readme.txt`:

- Personal use — allowed
- Commercial use — allowed
- **Redistribution/resale of the original files — NOT allowed**

**What this means for us:** shipping the art compiled inside a built game (APK or `.pck`)
is normal use and is fine. Committing the raw pack files, or publishing them as a
downloadable asset pack, is redistribution and is not.
